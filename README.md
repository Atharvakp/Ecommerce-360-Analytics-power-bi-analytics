# Shivratna Enterprises – Power BI Analytics Dashboard

An interactive Power BI business intelligence project designed to analyze
sales, customers, marketing, inventory, operations and returns for
Shivratna Enterprises.

## 📊 Project Overview

The Shivratna Enterprises Analytics Dashboard is a multi-page Power BI
solution developed to provide a 360° view of e-commerce business
performance.

The dashboard combines sales, customer, marketing, inventory and
operational data into an interactive analytical reporting solution.

## 🎯 Business Objective

The objective of this project is to transform raw e-commerce data into
actionable business insights that can support:

- Sales performance monitoring
- Revenue and profitability analysis
- Customer behavior analysis
- Marketing campaign evaluation
- Inventory monitoring
- Operational performance tracking
- Returns and refund analysis
- Data-driven business decision making
